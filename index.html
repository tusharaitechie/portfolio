Book Recommender
with MLOps

An end-to-end collaborative-filtering recommendation system that finds books with similar user-rating patterns and serves recommendations through a Streamlit interface.

WHAT I BUILT
  • Prepared Book-Crossing data through ingestion, validation, cleaning, filtering, and joining.
  • Created a book–user rating matrix and converted it to a SciPy CSR sparse matrix.
  • Trained a Scikit-learn NearestNeighbors model using cosine distance.
  • Organized the workflow into reusable pipeline stages and logged experiments with MLflow.
  • Defined reproducible pipeline stages with DVC and included Docker packaging.

FEATURED PROJECT · PRODUCTION-ORIENTED ML

US Visa Approval
Prediction

A supervised classification application that estimates an employment-based visa application outcome from employer, employee, job, wage, and location-related features.

WHAT I BUILT
  • Structured the ML lifecycle into data ingestion, schema validation, transformation, training, evaluation, and model pushing.
  • Built reusable components and separate training and prediction pipelines.
  • Connected application data workflows with MongoDB and model/artifact storage components for AWS S3.
  • Packaged the application with Docker and documented an AWS EC2/ECR deployment flow.
  • Included a GitHub Actions workflow for CI/CD automation and an interactive prediction interface.
