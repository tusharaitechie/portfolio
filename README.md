## Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

You need:

- Git
- A modern web browser
- Visual Studio Code (recommended)
- Python (optional, for local development server)

### 1. Clone the repository

```bash
git clone https://github.com/tusharaitechie/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Open the project

You can open `index.html` directly in your browser.

Alternatively, open the folder in VS Code:

```bash
code .
```

### 4. Run using Python

Start a local development server:

```bash
python -m http.server 8000
```

Open the following URL in your browser:

```text
http://localhost:8000
```

To stop the server, press `CTRL + C` in the terminal.

## Deployment Guide

This project is a static website, so it can be deployed without configuring a backend, database, or build pipeline.

### Option 1: Deploy on Cloudflare Pages

1. Push your portfolio code to GitHub.
2. Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/).
3. Open **Workers & Pages**.
4. Select **Create application** and choose **Pages**.
5. Connect your GitHub account.
6. Select the `portfolio` repository.
7. Configure the build settings:

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | Leave empty |
| Build output directory | `/` |
| Root directory | `/` |

8. Click **Save and Deploy**.

Cloudflare Pages will deploy your static website and provide a public URL.

You can also connect a custom domain later.

### Option 2: Deploy on Vercel

1. Visit [Vercel](https://vercel.com/).
2. Sign in using your GitHub account.
3. Click **Add New → Project**.
4. Import the `portfolio` repository.
5. Select **Other** as the framework preset, if prompted.
6. Leave the build command empty.
7. Set the output directory to `.` (project root).
8. Click **Deploy**.

Vercel will publish the portfolio and provide a deployment URL.

### Option 3: Deploy on Netlify

1. Visit [Netlify](https://www.netlify.com/).
2. Sign in using GitHub.
3. Select **Add new project → Import an existing project**.
4. Choose GitHub and select the `portfolio` repository.
5. Leave the build command empty.
6. Set the publish directory to `.` (project root).
7. Click **Deploy**.

Netlify will host the static portfolio.
